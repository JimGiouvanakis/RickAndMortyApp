# Rick and Morty App  

A simple and fun Rick and Morty app that fetches character, episode, and location data using the [Rick and Morty API](https://rickandmortyapi.com/).  

## Features  
- Browse all characters from the Rick and Morty universe.  
- View character details, including species, status, and origin.  
- Explore episodes and locations.  

## Tech Stack  
- **Frontend:** SwiftUI  
- **API:** [Rick and Morty API](https://rickandmortyapi.com/)  

## Design Note  
This project is built as an educational exercise, so the design is intentionally kept simple and minimalistic to focus on functionality and learning.
